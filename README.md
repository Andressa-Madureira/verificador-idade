# Verificador de Idade
Este é um projeto de verificação de idade desenvolvido com HTML, CSS, e JavaScript. Ele calcula a idade do usuário com base no ano de nascimento fornecido e identifica o gênero selecionado, exibindo uma imagem correspondente.

🛠️ Tecnologias Utilizadas
<ul>
  <li>HTML: Estrutura da página</li>
  <li>CSS: Estilização e design responsivo</li>
  <li>JavaScript: Lógica de cálculo e manipulação do DOM</li>
</ul>

🚀 Funcionalidades
<ul>
  <li>Verifica a idade com base no ano de nascimento inserido</li>
  <li>Identifica o gênero selecionado (masculino ou feminino)</li>
  <li>Exibe uma imagem representativa de acordo com a faixa etária e gênero</li>
</ul>

📂 Estrutura do Projeto
<ul>
  <li>HTML: Formulário para entrada de dados e exibição de resultados</li>
  <li>CSS: Estilização e responsividade</li>
  <li>
JavaScript: Lógica para calcular idade e alterar o conteúdo dinamicamente</li>
</ul>
